# Couchbase (couchbase)

Couchbase is a distributed, document-oriented NoSQL cloud database platform that combines JSON flexibility, SQL++ querying, and in-memory key-value performance. The product line spans Couchbase Server, Capella database-as-a-service, Sync Gateway and App Services for mobile / edge sync, and Couchbase Lite embedded databases.
